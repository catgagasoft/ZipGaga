# ZipGaga

**An all-in-one archive & file toolkit for macOS — right in Finder.**

ZipGaga brings the file operations Mac users miss from Windows into Finder's right-click menu: browse, extract, create and edit archives without opening a separate app window and digging through folders.

## Features

**Finder integration**
Compress, extract and manage files from the right-click menu — no separate app window, no ceremony.

**50+ formats**
Browse and extract ZIP, 7z, RAR, TAR, ISO, DMG, VHD/VHDX, ZSTD and many more. Create archives in 7z, ZIP, TAR, gzip, bzip2, xz and other formats.

**Edit inside archives**
Open a file inside an archive, edit it, save — ZipGaga repacks it for you. No manual extract-edit-recompress dance.

**Cross-Platform Clean Mode**
Sharing archives with Windows users? Clean Mode strips `.DS_Store` and `__MACOSX` junk so the other side never sees it.

**Passwords, handled**
AES-256 encryption for the archives you create, and a password manager stored in your macOS Keychain that auto-fills passwords for the archives you open.

**Split volumes that just work**
Double-click any volume of a split archive — ZipGaga finds the rest and extracts. Missing a volume? It tells you exactly which file is missing, in plain language.

**File utilities**
Right-click extras such as New File, Copy Path and Show Hidden Files, built into the same menu.

## FAQ

**Is ZipGaga open source?**
No. ZipGaga is a commercial app; this repository is its product page and feedback channel, not a source-code release.

**Does ZipGaga upload my files anywhere?**
No. ZipGaga works entirely on your Mac — no servers, no uploads. Your archives never leave your machine.
